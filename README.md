**Neon Drift** is a 90-second arcade run in a neon asteroid field. You pilot a courier ship with WASD or the arrow keys — thrust is strong but momentum barely fades, so the ship drifts and every change of direction is a small negotiation with physics. The job: bank 1300 points of glowing star shards before the clock runs out. Each shard is worth 10 points times your combo multiplier, and the multiplier climbs with every catch but drains away if you stop collecting, so the fastest route is a greedy one. The field fights back: asteroids spawn faster and quicker as the run goes on, each hit costs 25 of your 100 hull, and only the occasional green repair cell (+25) keeps a battered ship flying. Reach 1300 for the win screen; lose your hull or run out of time and the run ends. P pauses, M mutes the WebAudio-synthesized sound effects, and R, Enter or a click restarts from either end screen; any move key or a click launches from the title screen. Everything is plain static files — canvas rendering, no libraries, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
